# F4a: Language foundation (texts in ARB files, both dish names, Ethiopic font) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every text in the waiter and kitchen apps comes from English/Amharic ARB files, dish and option names show in both languages, and the Noto Sans Ethiopic font is bundled — while the app still runs in English (no language switch yet).

**Architecture:** Flutter `gen-l10n` generates `AppLocalizations` from `lib/l10n/app_en.arb` (template) and `app_am.arb`; a missing Amharic key fails the build. `MaterialApp` gets the delegates and a fixed `Locale('en')` (F4b replaces it with a provider). Code without a `BuildContext` (alerts, keep-alive notification) receives an `AppLocalizations Function()` that defaults to English. Dish names go through one small helper (`lib/l10n/names.dart`) and one widget (`DishName`).

**Tech Stack:** Flutter 3.44.9, Riverpod, drift, `flutter_localizations` (SDK), `intl` (version chosen by the SDK), Noto Sans Ethiopic (OFL).

**Spec:** `docs/superpowers/specs/2026-11-17-f4-amharic-english-design.md` (sections 5.4, 5.5, 6, step 1 of 7).

## Global Constraints

- Approved dependencies only: `flutter_localizations` (sdk: flutter), `intl` (via `flutter pub add intl:any`, so the SDK pins it), font files. Nothing else.
- In F4a the app's locale is fixed to `Locale('en')`: **every existing English text and test stays exactly as it is** (the 205 app tests are the proof nothing visible changed, apart from both dish names).
- Supported locales: `en`, `am`. Numbers, prices and times stay in Western digits.
- Amharic texts are drafts; each ARB entry has an `@description` saying where it appears (for the user's review in F4d).
- Dish names: big = name in the current language, small = the other; no Amharic name → English only, never an empty line. Option names: stored on lines as `"Large · ትልቅ"` (English first; English only when there is no Amharic).
- No server change in F4a. No drift schema change.
- Commit on the feature branch after tests pass; CI must be green before the PR is merged.

## Review Focus

1. A dish or option **without an Amharic name** must show English alone, with no empty second line — tested in Task 2.
2. A **long Amharic dish name** on a 360 dp phone at 1.3x text must wrap, not overflow — tested in Task 6 (fixture name of 40+ Ethiopic characters).
3. A translation that **drops a placeholder** (e.g. `{minutes}`) would silently lose the number — tested in Task 3 (`LOCKED` in Amharic contains `5`).
4. **Lines stored before F4a** keep their old option text `"Large, Spicy"` and must still display — tested in Task 2.
5. An **unknown error code** still gives a readable sentence with the code, in both languages — tested in Task 3.
